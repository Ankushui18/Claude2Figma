How it works

  1. For Claude → Figma: capture in Chrome, then drop or paste the JSON here.
  2. For Figma canvas copy: use the Copy Figma canvas tab above. Figma's WebGL canvas cannot be read by Chrome, so this plugin reads the native layers itself.
  3. Choose the artboard size before importing into this page or another Figma file.

Copy this Figma canvas

This runs entirely inside the plugin—there is no Chrome-extension connection. The plugin reads the native Figma layers and exports a local .deck.json that can be imported into another Figma page/file at 1920, 1600, 1440, mobile, original or custom sizes. The destination may be Figma desktop or a different Figma login.
